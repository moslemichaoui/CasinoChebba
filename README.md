CasinoChebba
CasinoChebba is a modern, fast, and responsive web application designed to deliver a smooth and reliable user experience.

Built With
React — UI library for building modular interfaces

TypeScript — Ensures type safety and cleaner code

Vite — Fast development server and build tool

Tailwind CSS — Utility-first styling for clean, responsive design

Getting Started
Prerequisites
Make sure you have Node.js (v18 or higher) installed on your system.

Quick Setup
Clone the project

Bash
git clone https://github.com/moslemichaoui/CasinoChebba.git
cd CasinoChebba
Install dependencies

Bash
npm install
Set up environment variables

Bash
cp .env.example .env
Start the local app

Bash
npm run dev
Open http://localhost:5173 in your browser.

Building for Production
To create a production-ready bundle, run:

Bash
npm run build
To test the production build locally before deploying:

Bash
npm run preview
